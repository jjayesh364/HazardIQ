# Demo Guide

To demonstrate the project to the SIH judges:
1. Run `npm run dev` and open the app.
2. Select **Scenario 1** and press **Start**. Point out the autonomous vehicle handling the unmarked road.
3. Switch to **Scenario 5 (Cattle Crossing)**. Demonstrate the `EMERGENCY_STOP` state triggering when the cattle suddenly moves.
4. Highlight the **Telemetry Dashboard** which displays real-time Replanning Latency (< 16ms), Speed, and Decision States.
5. Emphasize that the deterministic fallback ensures safety without relying purely on black-box AI.
